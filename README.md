# LEVEL DEVIL PAGLU — Darwaza Bhaag Gaya! 😈

Ek pagal troll-platformer game: tum darwaze tak pohonchne ki koshish karte ho, aur **poora level tumhein rokne ki koshish karta hai**. Darwaza bhaagta hai, zameen ghayab hoti hai, kaante phat parte hain — aur tum har maut par sirf hanste ho.

## ▶️ Khelo abhi (free, koi download nahi)

**https://sehrish64.github.io/level-pagal/**

Phone aur computer dono par chalta hai.

## 🎮 10 Levels, har level ek naya dhoka

1. **Pehla Dhoka** — pop-up kaante aur jaal wali zameen
2. **Chabi Aur Seedhi** — ghayab hoti seedhiyan, kaanton ke upar chaabi
3. **Teen Darwaze** — teen darwaze, asal sirf ek (sunehra sitara pehchano!)
4. **Dhakka Aur Chhat** — dhakka dene wali deewar, girti hui kaanton wali chhat
5. **Sab Kuch Ulta** — gravity ulta! Bhaagta hua darwaza
6. **Chhupa Darwaza** — asal darwaza ghayab hai, sirf ek sunehri chamak us ki nishaani hai
7. **Bhaagti Chabi** — chaabi bhi bhaagti hai, darwaza teleport hota hai, button wala jaal
8. **Darwaza Mela** — darwazon ki bheed, spring ke jaal, ulta gravity finale
9. **Aag Aur Goliyan** — aag ke sholay, goliyon ki baarish, upar seedhiyan
10. **Chalte Baksay** — chalte hue baksay, girne wale nakli baksay, jumping pads

## 🕹️ Controls

- **Computer:** Arrow keys / A,D se chalo, Space / W se kudo
- **Phone:** screen par diye gaye buttons
- Maro ge boht dafa — maut ka counter chal raha hai, doston se muqabla karo ke kon kam martta hai!

## 🎵 Apna gana lagao

Upar diye gaye **🎵 Gana** button se apne phone/computer ki koi bhi song file select karo — wohi game ka background music ban jayegi, aur game use yaad bhi rakhega.

## ✨ Khaas batein

- Slim-fit pehlwan character, hilte hue baadal, apni bani hui chiptune dhun
- Har maut par ek naya Roman Urdu tana (taunt) — "Wah beta wah!", "Phir mar gaye? Shocking!"
- **Bolne wale taanay (Urdu voice narration)** — ab game sirf likhta nahi, BOLTA bhi hai: marne par "Hahahaha!" aur "Chhoti bachi ho kya?", khatre ke paas jane par "Mara mara!" / "Gir jaye ga!", hosla dene ke liye "Tum kar sakte ho!", aur jeet par pura jashn. Saath mein **Afghani truck horn** — darwaza bhaage ya dhakka-deewar aaye to "paaan paaa!"
- Sirf **ek HTML file** mein poora game — koi asset, koi download, koi ads nahi
- 📱 **Install karo, offline khelo** — game ko phone ki home screen par app ki tarah lagao; pehli dafa kholne ke baad **baghair internet ke bhi poora chalta hai** (load-shedding ho ya data khatam!)
